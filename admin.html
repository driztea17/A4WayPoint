Hub admin

For district editors. Update the locked Resource Hub data, or change the district passcode. Everything happens in your browser. Nothing is sent anywhere.

Step 1. Enter the current passcode

Edit hub data

  1. Pick a list and select Download readable file.
  2. Open the .json file in a text editor and make your changes. Keep the commas and quotes. See the README for examples.
  3. Select the edited file below and choose Encrypt file.
  4. On GitHub, open the data folder, choose Add file, then Upload files, and upload the .enc.json file. It replaces the old one.

Change the district passcode

Use a long passcode that is hard to guess, for example four random words. After the change, members must use the new passcode.

At least 10 characters.

This downloads 6 files: hub.lock.json and one .enc.json file for each list. Upload all 6 to the data folder on GitHub at the same time. Your browser may ask to allow several downloads.
